## 🌟 Why Global Boutique Manager?

In today's fast-paced commercial environment, speed, precision, and data availability are critical. **Global Boutique Manager** is a comprehensive, all-in-one software solution designed to automate your point of sale, secure your inventory, and maximize your profits—even in areas with unstable internet connectivity.

While configured by default for the **Franc Congolais (CDF)**, the system is fully adaptable to any international currency and tax regulation, making it the perfect partner for retail businesses globally.

---

## 🚀 Key Features

### 🛒 Intelligent Point of Sale (POS)
*   **Rapid Checkout**: Fluid interface to serve customers in seconds.
*   **Professional Invoicing**: Instant PDF generation for receipts and invoices.
*   **Taxes & Discounts**: Automated management of VAT and commercial discounts.
*   **Flexible Payments**: Support for cash, credit, and mobile payments.

### 📦 Precision Inventory Management
*   **Real-Time Stock Tracking**: Rigorous monitoring of stock ins and outs.
*   **Movement Journals**: Detailed history of every stock adjustment (Entry/Exit) for total traceability.
*   **Low-Stock Alerts**: Automatic notifications to prevent stockouts.
*   **Valuation**: Automated calculation of capital value (Purchase vs. Selling price).

### 💰 Finance & Cashflow
*   **Expense Tracking**: Record operational costs (rent, utilities, salaries) for clear profit visibility.
*   **Debt Recovery**: New specialized payment module to settle customer debts with full historical tracking.
*   **Live Cashflow**: Real-time visualization of business liquidity.

### 🤝 Strategic CRM & Suppliers
*   **Supplier Professional Profiles**: Complete history of purchases per supplier to negotiate better terms.
*   **Customer Loyalty**: Complete purchase history and points-based rewards.

### 👥 Advanced HR Module
*   **Team Management**: Comprehensive employee registration, role assignment, and secure access control.
*   **Presence Tracking**: Monitor active staff and leaves in real-time.

### 📊 Advanced Reporting
*   **Dynamic Dashboard**: Daily revenue, profits, and sales trends.
*   **Exportable Reports**: Periodic balance sheets for simplified accounting.

## 💎 The Enterprise Advantage

1.  **Offline-First Performance (PWA)**: The system works seamlessly without internet. Data synchronizes automatically once a connection is established.
2.  **Multi-Currency Support**: Native support for multiple currencies with real-time exchange rate configuration.
3.  **Maximum Security**: Audit logs monitor all sensitive actions taken by personnel.
4.  **Modern & Responsive Design**: A high-end, clean interface accessible on PC, tablet, or smartphone.

## 🛠️ Technical Specifications

*   **Frontend**: React 19 + Vite (Ultra-fast performance)
*   **Styling**: Tailwind CSS (Sophisticated, modern design)
*   **Database**: Dexie / IndexedDB (Secure local-first architecture)
*   **Animations**: Motion (Premium user experience)
*   **Icons**: Lucide React
*   **Charts**: Recharts

## 👨‍💻 Deployment & Development

1.  **Cloning**:
    ```bash
    git clone [repo-url]
    ```
2.  **Install Dependencies**:
    ```bash
    npm install
    ```
3.  **Start Dev Mode**:
    ```bash
    npm run dev
    ```
4.  **Production Build**:
    ```bash
    npm run build
    ```
